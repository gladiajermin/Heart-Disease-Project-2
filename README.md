# Heart Disease Prediction Project

Machine Learning model built and compared on the Heart Disease dataset, completed as Project 2 for the Pluto Academy AI/ML Internship.

## Dataset
Heart Disease Prediction Dataset
## What this project covers
- Loading and preprocessing the data (checking missing values, removing duplicates, stratified 80/20 train-test split, feature scaling)
- Feature engineering using a correlation matrix to review relationships between variables and the target
- Training and comparing 3 classification models: Logistic Regression, Random Forest, and K-Nearest Neighbors
- Evaluating all 3 models using Accuracy, Precision, Recall, and F1-Score
- Identifying the best performing model (Logistic Regression) with a confusion matrix and written conclusion
